✈️ Airline AI Assistant

An AI-powered airline assistant built with Generative AI and open-source image generation models.

Project Overview

This project allows users to interact with an AI airline assistant to check flight ticket prices and explore travel destinations.

Technologies Used

- Python
- Google Gemini 2.5 Flash
- OpenAI-compatible API
- Function Calling (Tool Calling)
- SQLite
- Hugging Face Diffusers
- Stable Diffusion 1.5
- PyTorch
- Gradio
- Google Colab

Features

- Conversational AI assistant.
- Function Calling to retrieve ticket prices.
- SQLite database for storing destination prices.
- AI-generated destination images using Stable Diffusion.
- Interactive Gradio interface.

How to Run

1. Open the notebook in Google Colab.
2. Select a GPU runtime.
3. Add "GEMINI_API_KEY" and "HF_TOKEN" through Colab Secrets.
4. Run the notebook cells in order.
5. Open the Gradio share link.
